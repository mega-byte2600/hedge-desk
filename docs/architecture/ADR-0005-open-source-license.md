# ADR-0005: Apache-2.0 open-source license

- Status: accepted
- Date: 2026-08-22

## Decision

License original Hedge Desk repository code and documentation under Apache
License 2.0. Contributions submitted for inclusion use the same terms unless
explicitly designated otherwise.

Apache-2.0 permits commercial and noncommercial use, modification, and
redistribution while providing explicit patent-license terms and preserving
notices. The public repository is therefore machine-detectable open source,
not merely publicly readable source code.

## Boundary

The license does not relicense third-party market data, model weights, books,
papers, trademarks, or vendor payloads. Those artifacts remain outside the
repository unless their own terms explicitly permit inclusion.
